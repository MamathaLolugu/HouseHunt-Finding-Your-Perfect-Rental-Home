### HouseHunt: Finding Your Perfect Rental Home ###

HouseHunt is a MERN Stack Rental Home Finder Application designed to help users easily search, filter, and find rental homes. This project provides a platform for tenants, property owners, and admin to manage rental listings efficiently.

### Project Overview ###

Finding a rental home is difficult due to unorganized listings and limited filtering options. HouseHunt solves this by providing a modern rental home management system where users can search homes and owners can post rental properties. Admin has full control over the platform.

### Features ###
👤 User (Tenant) Features

✅ User Registration & Login

✅ Secure Authentication using JWT

✅ Search rental homes easily

✅ Filter properties based on price, location, type, etc.

✅ View complete property details

✅ Responsive UI for mobile and desktop

🏡 Owner Features

✅ Add new rental property listing

✅ Post house details (rent, address, description, contact, etc.)

✅ Update rental property information

✅ Manage posted properties

🛡️ Admin Features

Admin plays an important role in managing the entire application.

Admin can:

✅ View all registered users

✅ View all property listings

✅ Approve or reject rental listings

✅ Delete fake or inappropriate property posts

✅ Remove users if any suspicious activity is found

✅ Monitor the overall platform activity

🔒 Security Features

✅ Password encryption (bcrypt)

✅ JWT token-based authentication

✅ Secure backend API access
